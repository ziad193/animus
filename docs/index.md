## Warm-up

- 5 min easy cardio
- 2–3 lighter sets of the first lift, working up to the top weight

## Progression

- Once every set hits the top of the rep range, add weight next session
  (about 2.5 kg for upper-body lifts, 5 kg for lower-body lifts)
- If a lift stalls for 3 sessions, take 10% off it and build back up
